# Roadmap

The roadmap is directional and driven by dashboard feedback.

## Near term

- Validate the compatibility matrix on supported Grafana 11, 12, and 13 releases.
- Add catalog screenshots and a signed alpha artifact.
- Exercise wide, long, invalid, empty, dense, dark, and light examples in E2E.

## Later

- Add data links and visualization suggestions when the minimum Grafana version supports those APIs safely.
- Improve label collision behavior based on representative dashboards.
- Stabilize the public contract and define non-alpha release criteria.
